Quick Start

Get up and running with automatic issue labeling in under 5 minutes.

1 Add the workflow file to your repository's .github/workflows/ directory
2 Configure your labels in the config.yml file
3 Create an issue and watch the magic happen!

Prerequisites

Before you begin, ensure you have:

  • A GitHub repository with issues enabled
  • Repository admin permissions (for label creation)
  • GitHub Actions enabled in your repository
  • Basic understanding of YAML configuration

Detailed Installation Steps

Step 1: Add the Workflow File

Create a new file at .github/workflows/auto-label-issues.yml in your repository:

# Copy this content to .github/workflows/auto-label-issues.yml name: Setup Issue Templates and Labels on: issues: types: [opened, edited] pull_request: types: [opened, edited, synchronize] repository_dispatch: types: [create_labels, cleanup, update] env: CREATE_TEMPLATES: ${{ vars.CREATE_TEMPLATES || 'true' }} CREATE_LABELS: ${{ vars.CREATE_LABELS || 'true' }} AUTO_LABEL_ISSUES: ${{ vars.AUTO_LABEL_ISSUES || 'true' }} jobs: create_issue_templates: runs-on: ubuntu-latest if: ${{ vars.CREATE_TEMPLATES != 'false' }} steps: - name: Checkout repository uses: actions/checkout@v3 - name: Setup Node.js uses: actions/setup-node@v3 with: node-version: '18' cache: 'npm' - name: Install dependencies run: npm ci - name: Generate Issue Templates run: npm run generate:templates
⚠️ Important: Make sure to commit and push this file to your repository's main branch.

Step 3: Trigger the Initial Setup

To create all labels and templates, trigger the workflow manually:

# Using GitHub CLI gh api repos/:owner/:repo/dispatches \ -f event_type=create_labels \ -f client_payload='{"action": "create_labels"}' # Or manually via GitHub web interface: # 1. Go to your repository # 2. Click "Actions" tab # 3. Select "Setup Issue Templates and Labels" # 4. Click "Run workflow"
✅ Success! Your labels and templates should now be created automatically.

Configuration Options

Environment Variables

You can control the behavior using repository variables:

# Set these in your repository Settings > Secrets and variables > Actions > Variables CREATE_TEMPLATES=true # Generate issue templates (default: true) CREATE_LABELS=true # Create GitHub labels (default: true) AUTO_LABEL_ISSUES=true # Auto-label new issues (default: true) RATE_LIMIT_DELAY=0.5 # Delay between API calls (default: 0.5s) MAX_RETRIES=3 # Max retries for failed operations (default: 3)

Customizing Labels

You can add custom labels by extending the config.yml:

# Add custom labels labels: custom: "🎨 Design": color: "ff6b6b" description: "Design-related tasks" "🔧 Bug Fix": color: "d73a4a" description: "Bug fixes and patches" "📚 Documentation": color: "0075ca" description: "Documentation updates"

Troubleshooting

Common Issues

Labels not created?
Check that you have admin permissions on the repository and that the workflow has the necessary permissions.
Rate limit errors?
Increase the RATE_LIMIT_DELAY variable to add more delay between API calls.
Templates not generated?
Ensure Node.js dependencies are installed and the generate:templates script is working.
