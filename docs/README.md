# DevLander Auto Label Issues - Documentation

This directory contains the documentation and landing page for the DevLander Auto Label Issues GitHub Action.

## 📁 Structure

- `index.html` - Main landing page with features, installation guide, and usage examples
- `_config.yml` - Jekyll configuration for GitHub Pages
- `README.md` - This file

## 🚀 GitHub Pages

This site is configured to be served via GitHub Pages. To enable it:

1. Go to your repository settings
2. Navigate to "Pages" in the sidebar
3. Select "Deploy from a branch"
4. Choose the `main` branch and `/docs` folder
5. Click "Save"

The site will be available at: `https://devlander-software.github.io/issue-labler`

## 🎨 Features

The landing page includes:

- **Modern Design**: Gradient backgrounds, animations, and responsive layout
- **Feature Showcase**: Comprehensive overview of all action capabilities
- **Installation Guide**: Step-by-step setup instructions
- **Usage Examples**: Real-world examples with expected outputs
- **Template Documentation**: Overview of all available issue templates
- **Analysis Features**: Information about data analysis and insights
- **Mobile Responsive**: Works perfectly on all device sizes

## 🔧 Customization

To customize the landing page:

1. Edit `index.html` to modify content, styling, or layout
2. Update `_config.yml` to change site metadata
3. Add new pages by creating additional HTML files
4. Modify colors, fonts, and styling in the CSS section

## 📊 SEO Optimization

The page includes:

- Meta tags for search engine optimization
- Structured content with proper headings
- Keywords relevant to GitHub Actions and issue management
- Fast loading with optimized CSS and minimal external dependencies

## 🌐 Deployment

The site automatically deploys when changes are pushed to the main branch. GitHub Pages will build and serve the content from the `/docs` directory.
